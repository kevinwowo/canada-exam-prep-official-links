## Official sources (start here)

| Exam | Official study source | Notes |
|---|---|---|
| Canadian citizenship | [Discover Canada (IRCC)](https://www.canada.ca/en/immigration-refugees-citizenship/corporate/publications-manuals/discover-canada.html) | IRCC states Discover Canada is the only official study guide for the citizenship test. |

## Study routine (handbook-first)

1. Read the official guide for your exam (table above).
2. Take one full-format practice run on [canadaexamprep.com](https://canadaexamprep.com).
3. Review every miss against the handbook section, not against "what the app said."
4. Repeat until practice scores are stably high, then book the real test.
